# Recomp Zwölf Wochen

Private Trainings-App für einen 12-Wochen-Block: Plan, Protokoll, Übungslexikon,
Wochenbilanz und eine Pausenuhr, die auch im Hintergrund weiterläuft.

Eine einzelne HTML-Seite ohne Server und ohne Konto. Alle Daten bleiben im
Browser des Geräts; Sicherung und Einspielen stecken in den Einstellungen.

Am iPhone: Adresse in Safari öffnen, Teilen → „Zum Home-Bildschirm“.
Danach startet sie wie eine App und funktioniert auch ohne Internet.
